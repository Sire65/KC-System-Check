# Abfrageregeln

1. Live-Status verwendet ausschließlich den neuesten abgeschlossenen Lauf.
2. Historie dient nur Trend/Archiv und darf aktuelle Befunde nicht überschreiben.
3. One Touch startet nur Adapter, die real konfiguriert und prüfbar sind.
4. Fehlende Direktanbindungen bleiben grau/deaktiviert statt künstlich grün.
5. Für 100 % müssen alle im Lauf enthaltenen aktiv konfigurierten Systeme gesund sein.
6. Schwere Kapazitäts-/Historienabfragen werden technisch von schnellen Healthchecks getrennt, sobald die zugehörige Servermigration produktiv aktiv ist.
