KC SYSTEM CHECK - LAUFFAEHIGE WINDOWS-VERSION
=============================================

1. ZIP vollstaendig in einen Ordner entpacken.
2. START_KC_SYSTEM_CHECK.cmd doppelklicken.
3. Das schwarze Fenster geoeffnet lassen.
4. Der Browser oeffnet automatisch http://127.0.0.1:8765/
5. Zum Beenden das schwarze Fenster schliessen oder STRG+C druecken.

Hinweis:
- Die Startdatei schaltet die Windows-Konsole auf UTF-8 um.
- Diese Version benoetigt keine Installation und keinen Python-Server.
- Windows PowerShell ist in Windows 10/11 vorhanden.
- Fuer LIVE-Daten benoetigt KC System Check weiterhin Internetzugang zu den konfigurierten Supabase-/GitHub-Diensten.
- Die ZIP enthaelt keine geheimen Server-Schluessel.
